# csc102-the-foundation

## CSC102: The Foundation

**Course:** CSC102 – Introduction to Programming  
**Assignment:** 1.2 – The Foundation  
**Author:** Evan Ketchum  
**Term:** Summer 2026

This project contains the HTML, CSS, and JavaScript pages created for CSC102. It introduces the basic structure of webpages using HTML5, page styling using CSS, and an interactive JavaScript game.

## Pages

- `index.html` – The home page with a welcome message.
- `boards.html` – Program objectives for the Associate degree in Artificial Intelligence.
- `game.html` – Meteor Dodge, an original keyboard game.
- `main.css` – Shared page and game styling.
- `code.js` – JavaScript used by Meteor Dodge.

## How to use

Open `index.html` in a modern web browser. Use the navigation links to open the other pages. On the game page, select **Start Game** and use the left and right arrow keys to avoid meteors.
